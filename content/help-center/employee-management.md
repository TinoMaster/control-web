## Agregar un empleado

1. Ve a la pestaña **Gestión General** en el menú inferior
2. Toca en **"Empleados"**
3. Toca el botón **"+"** en la esquina inferior derecha
4. Completa los datos del empleado:
   - Nombre completo
   - Número de teléfono (opcional)
   - Cargo o función (ej: "Operador de copias", "Diseñador")
5. Toca **"Guardar"**

## Configurar el tipo de salario

Después de crear el empleado, configura cómo se le paga:

| Tipo | Cuándo usarlo | Ejemplo |
|------|---------------|---------|
| **Fijo** | Salario mensual o quincenal fijo | $3,000/mes |
| **Comisión** | Porcentaje de cada venta que realiza | 10% de las ventas |
| **Mixto** | Salario base + comisión por ventas | $1,500/mes + 5% de ventas |

Para configurarlo:

1. Toca sobre el empleado en la lista
2. Toca **"Configurar salario"**
3. Selecciona el tipo (Fijo, Comisión o Mixto)
4. Ingresa el monto o porcentaje
5. Toca **"Guardar"**

## Registrar un pago

Cuando le pagas a un empleado:

1. Ve a **Gestión General → Empleados**
2. Toca sobre el empleado
3. Toca **"Registrar pago"**
4. Ingresa el monto pagado
5. Selecciona la fecha del pago
6. Agrega un concepto (ej: "Pago quincena enero 1-15")
7. Toca **"Confirmar"**

El pago quedará registrado en el historial del empleado.

## Ver el historial de pagos

1. Toca sobre el empleado
2. Toca **"Historial de pagos"**
3. Verás todos los pagos realizados con fecha, monto y concepto
4. Puedes filtrar por período

## Comisiones automáticas (módulo POS)

Si tu empleado atiende ventas en el punto de venta:

1. Configura el porcentaje de comisión en **"Configurar salario"**
2. Cada vez que el empleado registre una venta, el sistema calcula su comisión automáticamente
3. Las comisiones aparecen en el reporte del empleado

## Roles y permisos

Cada empleado puede tener un rol que determina qué puede hacer en la app:

| Rol | Qué puede hacer |
|-----|-----------------|
| **USER** | Registrar ventas, ver su propio historial |
| **ADMIN** | Todo lo de USER + gestionar empleados, ver reportes, anular ventas |
| **OWNER** | Todo lo de ADMIN + configurar el negocio, precios y roles |
| **SUPERADMIN** | Acceso total a todos los negocios de la cuenta |

Para cambiar el rol de un empleado:

1. Toca sobre el empleado
2. Toca **"Editar"**
3. Cambia el rol en el selector
4. Toca **"Guardar"**

> **Recomendación**: En un centro de copias, los operadores suelen tener rol **USER**. Solo el dueño o encargado debería tener rol **ADMIN** u **OWNER**.

## Eliminar un empleado

1. Toca sobre el empleado
2. Toca **"Editar"**
3. Toca **"Eliminar empleado"**
4. Confirma la acción

> Los pagos e historial del empleado se conservan para auditoría, aunque ya no aparezca en la lista activa.
